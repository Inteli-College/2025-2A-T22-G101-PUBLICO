## Public Report — Module 16

### Machine Learning for Dynamic Bitcoin Allocation: A Risk-Adjusted, Long-Only Strategy

- 📘 [`Public Report G101 M16.docx`](./Public%20Report%20G101%20M16.docx) — full report (Word, INTELI TCC template format)
- 📄 [`Public Report G101 M16.pdf`](./Public%20Report%20G101%20M16.pdf) — full report (PDF)
- 📝 [`Public Report G101 M16.md`](./Public%20Report%20G101%20M16.md) — source (Markdown)

A machine-learning system that decides, on a weekly basis, how much of a portfolio to
allocate to Bitcoin versus a cash-equivalent benchmark (the Brazilian interbank rate,
CDI). It is long-only (0–100%, no short selling) and optimized for **downside
risk-adjusted return**. The report covers the problem, methodology, results, and
limitations.

> **Confidentiality.** Confidential partner information (assets under management, client
> data, and proprietary implementation details) has been intentionally omitted.
> Performance figures are out-of-sample backtest and early paper-trading results, not
> realized returns on capital.
